# Privacy And Public Portfolio Policy

This repository is designed to be public, but the full athlete dataset should not be public by default.

## Keep Private

- Garmin and Strava exports.
- FIT, GPX, TCX, CSV, ZIP, and PDF source files.
- Sleep data.
- Cardiopulmonary or medical test files.
- Full personal training and race databases.
- Any file that exposes exact home routes, timestamps, or health measurements.

## Safe To Publish

- Source code.
- Documentation.
- Sanitized sample data.
- Generated charts when the athlete explicitly wants them public.
- Aggregated metrics that do not expose raw routes or medical documents.

## Repository Rule

The public repository should show how the system works without becoming a raw archive of private health and location data.
